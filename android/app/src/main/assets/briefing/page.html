How stories are rated. Each story gets 0–3 on six criteria, each with the fact behind it. The sliders set how much each criterion counts compared with the others (they are remembered for every briefing). The score is 0–100: one strong criterion is enough to lift a story, and each further one lifts it more, so a deadly attack does not also need to be surprising to rank high. The +numbers show each criterion's share of the score. Critical is 70+, High 50+, Notable 25+, Routine below. Reports of the same event are merged under one story (open "more reports" to see them), different stories about one ongoing situation are grouped into a storyline, and no single area takes more than about a third of the list. {{RATED_BY}}

  • Severity: harm to lives, safety, rights or money
  • Scale: how many people it reaches (local, national, international)
  • Urgency: whether it is unfolding now or needs action soon
  • Interest: how surprising, new or revealing it is
  • Coverage: how many sources report the same event
  • Relevance: whether it touches your tracked topics or region
